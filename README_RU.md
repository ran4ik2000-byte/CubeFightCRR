# CUBEFIGHT — подготовка к публикации

В проекте уже собран исходный игровой сайт, переименованный в **CUBEFIGHT**, с маршрутами страниц, Gmail-входом, облачным сохранением, кодом друга и приглашениями в игру.

## Что сохраняет аккаунт

- монеты, инвентарь и экипировку;
- рекорд и настройки игры;
- язык и настройки управления;
- список друзей и постоянный 8-значный код;

Один адрес `@gmail.com` соответствует одной записи Supabase Auth. База также проверяет Gmail на сервере, а не только в форме.

## 1. Подготовь Supabase

В Supabase SQL Editor выполни файл `supabase/schema.sql` целиком. Он создаёт таблицы профиля/друзей, приватный доступ, уникальные коды и проверку Gmail. Функции передачи подарков удалены.

В Supabase → Authentication → URL Configuration:

1. поставь адрес сайта как **Site URL**;
2. добавь `https://ТВОЙ-ДОМЕН/glavmenu/` в **Redirect URLs**;
3. оставь подтверждение почты включённым, если хочешь подтверждать Gmail перед входом.

В `public/index.html` уже указаны URL Supabase и публичный `publishable` ключ из исходного файла. Локальные библиотеки сайта лежат в `public/vendor/`. Публичный ключ предназначен для браузера; **не добавляй туда `service_role`/secret key**. Если ключ или проект не твои — замени оба значения в блоке `SUPABASE_URL` / `SUPABASE_PUBLIC_KEY`.

## 2. Опубликуй на Cloudflare Workers

Из папки проекта установи зависимости, войди в свой Cloudflare аккаунт и опубликуй Worker:

```bash
npm install
npx wrangler login
npx wrangler deploy
```

Для локального запуска перед публикацией используй `npm run dev`.

`wrangler.jsonc` настроен на папку `public` и режим SPA: прямые адреса вроде `/glavmenu/`, `/settings/`, `/inventory/`, `/cases/`, `/shop/`, `/friends/`, `/connect/`, `/join/`, `/room/`, `/pause/` и `/game/` будут открывать нужный экран. Название Worker можно изменить в `wrangler.jsonc`, если оно уже занято.

Для публикации на уже существующий Worker выбери тот же Worker в Cloudflare Dashboard или укажи его фактическое имя в `wrangler.jsonc`.



## FPS, настройки, никнейм и рейтинг

- В настройках можно выбрать лимит до 120 FPS, до 60 FPS или без ограничения. 120 FPS — максимум; фактическая частота зависит от экрана, браузера и устройства.
- Счётчик FPS показывается в настройках и во время игры; в главном меню он скрыт. Отображение во время игры можно переключить в настройках.
- При регистрации нужен уникальный ник длиной 3–8 символов: буквы, цифры, `_` или `-`. Сменить ник можно из настроек; сервер ограничивает смену одним разом в 3 дня.
- Таблица лидеров видна только в главном меню; сортировка — по пройденным волнам, монетам и времени в игре.
- Для никнеймов, рейтинга и ограничения смены ника выполни актуальный `supabase/schema.sql` в Supabase SQL Editor, затем опубликуй обновлённый сайт.

## 3. Проверка после публикации

1. Открой сайт по HTTPS, зарегистрируй Gmail и подтверди письмо.
2. Создай второй аккаунт на другом Gmail, добавь коды друг друга и проверь приглашение в игру.
3. Обнови страницу и проверь, что инвентарь, настройки и рекорд восстановились.
4. Проверь ссылки `/glavmenu/` и `/friends/` напрямую.

## Важно перед запуском

- Сайт подготовлен для публикации, но ещё не развёрнут: для выкладки нужен доступ к вашему аккаунту Cloudflare. В `wrangler.jsonc` уже задано имя Worker `cubefightcrr`.
- Платёжный провайдер не подключён; магазин монет не имитирует оплату.
- Игровая экономика и награды пока сохраняются из браузера, поэтому проект не следует считать защищённым от читов или использовать для платных/соревновательных балансов без авторитетной серверной логики.
- После входа выбор устройства сохраняется в браузере; при следующем посещении игра открывает главное меню без повторного выбора. Очистка данных сайта сбрасывает этот выбор.
