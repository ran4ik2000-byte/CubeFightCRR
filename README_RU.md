# CUBEFIGHT — панель управления

Отдельная панель открывается по адресу `/admin` (также доступен `/console`). Она использует Cloudflare Worker и Supabase REST/Auth API. Пароль, service-role key и подпись сессий не находятся в HTML/JavaScript браузера.

## Что есть в панели

- Список игроков: никнейм, почта, UUID и баланс монет; поиск по нику, почте и ID.
- Блокировка/разблокировка входа в аккаунт через Supabase Auth.
- Блокировка локальной игры для аккаунта.
- Выдача и списание монет.
- Каталог всех 160 предметов из прикреплённой версии игры: ID, игровые иконки и параметры (урон, защита или сытость); выдача предметов в профиль.
- Настройка цен кейсов и пакетов монет, добавление новых пакетов и ссылка на Telegram.
- Журнал административных действий; статусы игроков и журнал обновляются автоматически.
- Смена пароля панели; пароли хранятся только как PBKDF2-хеш.

## Установка

1. Разместите содержимое этой папки в репозитории Worker. В `public/` находятся сайт и локальные библиотеки; каталог и иконки лежат рядом.
2. В Supabase SQL Editor выполните `supabase/schema.sql`, если базовая схема ещё не запускалась, затем `supabase/admin_migration.sql`.
3. В терминале из папки проекта установите Wrangler и задайте секреты:

   ```sh
   npm install
   npx wrangler secret put SUPABASE_SERVICE_ROLE_KEY
   npx wrangler secret put ADMIN_INITIAL_PASSWORD
   npx wrangler secret put ADMIN_SESSION_SECRET
   ```

   Для `SUPABASE_SERVICE_ROLE_KEY` возьмите service-role/secret key проекта Supabase. Вводите его только в Cloudflare/Wrangler, никогда не вставляйте в HTML, репозиторий или чат. Для `ADMIN_SESSION_SECRET` используйте случайную строку не короче 32 символов. Начальный пароль задаётся интерактивно при `wrangler secret put` и нигде в исходниках не записывается. Пароль, отправленный в чате, следует считать раскрытым и заменить новым до публикации.

4. Для локальной разработки скопируйте `.dev.vars.example` в `.dev.vars`, заполните значения локально и не добавляйте этот файл в Git.
5. Запустите `npm run dev`, проверьте `/console`, затем опубликуйте командой `npm run deploy`.
6. После первого входа смените начальный пароль в разделе **Безопасность**. Новый пароль — не менее 12 символов.

## Важные ограничения

- `/console` — удобный отдельный адрес, а не секретная защита. Доступ защищают серверная проверка пароля, HttpOnly-сессия и ограничения API.
- Блокировка аккаунта применяется через Supabase Auth и скрывает игрока из рейтинга. Ограничение локальной игры обновляется на клиенте примерно за 5 секунд; локальный режим без серверной авторитетной логики нельзя сделать полностью защищённым от модифицированного клиента.
- Цены пакетов и кейсов обновляются в игре автоматически. Новые пакеты монет видны в магазине, но принять оплату и начислить покупку нельзя, пока отдельно не подключён платёжный провайдер; одного изменения цены для оплаты недостаточно.
- Все изменения каталога, настроек и аккаунтов проходят через Worker с service-role key; обычный клиент не получает этот ключ.
