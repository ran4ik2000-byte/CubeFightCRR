# CUBEFIGHT — подготовка к публикации

В проекте уже собран исходный игровой сайт, переименованный в **CUBEFIGHT**, с маршрутами страниц, Gmail-входом, облачным сохранением, уникальным кодом друга и безопасной передачей монет/предметов между друзьями.

## Что сохраняет аккаунт

- монеты, инвентарь и экипировку;
- рекорд и настройки игры;
- язык и настройки управления;
- список друзей и постоянный 8-значный код;
- подарки монет и предметов отправляются только друзьям и списываются с аккаунта отправителя.

Один адрес `@gmail.com` соответствует одной записи Supabase Auth. База также проверяет Gmail на сервере, а не только в форме.

## 1. Подготовь Supabase

В Supabase SQL Editor выполни файл `supabase/schema.sql` целиком. Он создаёт таблицы профиля/друзей, политику приватного доступа, уникальные коды, проверку Gmail и транзакционные функции подарков.

В Supabase → Authentication → URL Configuration:

1. поставь адрес сайта как **Site URL**;
2. добавь `https://ТВОЙ-ДОМЕН/glavmenu/` в **Redirect URLs**;
3. оставь подтверждение почты включённым, если хочешь подтверждать Gmail перед входом.

В `public/index.html` уже указаны URL Supabase и публичный `publishable` ключ из исходного файла. Публичный ключ предназначен для браузера; **не добавляй туда `service_role`/secret key**. Если ключ или проект не твои — замени оба значения в блоке `SUPABASE_URL` / `SUPABASE_PUBLIC_KEY`.

## 2. Опубликуй на Cloudflare Workers

Из папки проекта установи зависимости, войди в свой Cloudflare аккаунт и опубликуй Worker:

```bash
npm install
npx wrangler login
npx wrangler deploy
```

Для локального запуска перед публикацией используй `npm run dev`.

`wrangler.jsonc` настроен на папку `public` и режим SPA: прямые адреса вроде `/glavmenu/`, `/settings/`, `/inventory/`, `/cases/`, `/shop/`, `/friends/`, `/connect/`, `/join/`, `/room/`, `/pause/` и `/game/` будут открывать нужный экран. Название Worker можно изменить в `wrangler.jsonc`, если оно уже занято.

Для публикации на уже существующий Worker выбери тот же Worker в Cloudflare Dashboard или укажи его фактическое имя в `wrangler.jsonc`.

## 3. Проверка после публикации

1. Открой сайт по HTTPS, зарегистрируй Gmail и подтверди письмо.
2. Создай второй аккаунт на другом Gmail, добавь коды друг друга и проверь передачу монет/предмета.
3. Обнови страницу и проверь, что инвентарь, настройки и рекорд восстановились.
4. Проверь ссылки `/glavmenu/` и `/friends/` напрямую.

## Важно перед запуском

- Сайт подготовлен для публикации, но ещё не развёрнут: для выкладки нужен доступ к вашему аккаунту Cloudflare. В `wrangler.jsonc` уже задано имя Worker `cubefightcrr`.
- Платёжный провайдер не подключён; магазин монет не имитирует оплату.
- Передачи между друзьями выполняются серверной транзакцией. Остальная игровая экономика и награды пока сохраняются из браузера, поэтому проект не следует считать защищённым от читов или использовать для платных/соревновательных балансов без авторитетной серверной логики.
